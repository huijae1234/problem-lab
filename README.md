# 문제 발굴소

막연한 불편을 **확인 가능한 문제 한 문장**으로 다듬고, 실제로 확인한 뒤 다시 돌아와 결과까지 남기는 로컬 웹 도구입니다. 기존 두더지 캐릭터, 발굴 깊이, 카드 한 장씩 진행하는 방식은 유지했습니다.

## 핵심 사용 흐름

문제 입력 → 원인을 질문하며 파기 → 사실과 추측 구분 → 가설과 확인 방법 작성 → 필요하면 더 깊이 파기 → 최종 문제 한 문장 확정 → 확인하러 가기 → 기록으로 돌아와 검증 결과 입력 → 최종 문제 수정 또는 확정

이슈 트리, 5 Hows, 피시본, SCQA, 바이브코딩 프롬프트는 기본 흐름에서 강요하지 않고 `더 깊이 파기`에서 고르는 선택 도구로 두었습니다.

## 주요 기능

- 5 Whys와 원인 후보마다 `확인된 사실`, `아직 추측`, `확인 필요`, `확인 결과와 맞지 않음`을 구분합니다.
- 근거·출처와 확인 방법을 함께 기록합니다.
- 최종 문제, 사실, 추측, 확인 질문, 가설, 반례, 작은 확인 방법, 다음 행동을 한 화면에서 정리합니다.
- 앞 단계에서 표시한 사실·추측·확인 질문을 최종 결과에 자동으로 모읍니다. 사용자가 고친 뒤 필요할 때 다시 불러올 수 있습니다.
- AI가 연결되어 있으면 최종 문제 한 문장 초안을 요청할 수 있지만, 자동 확정하지 않습니다.
- 검증 뒤 같은 기록으로 돌아와 결과와 달라진 점을 남깁니다. 최종 문제를 바꾸면 이전 문장도 변경 기록에 보존됩니다.
- 작성 중, 확인하러 감, 검증 결과 입력 필요, 발굴 완료 상태를 구분합니다.
- 제목 변경, 태그, 검색, 상태 필터, 전체 복사, 텍스트 내보내기를 지원합니다.
- 입력이 부족해도 강제로 막지 않고 돌아가기·건너뛰기·계속하기 중에서 고를 수 있습니다.
- 건너뛰기와 부족한 상태로 계속하기를 구분해 최종 결과에 진행 메모로 남깁니다.
- 경험치는 실제 작성·구분·검증 행동으로만 오릅니다. AI의 점검은 현재 내용의 `충분함`, `보완 필요`, `비어 있음`으로 따로 보여 줍니다.
- 브라우저에 자동 저장하므로 AI가 꺼져도 작성·이동·저장·기록 열람이 가능합니다.
- 기록 화면은 작성 중·확인하러 감·결과 입력 필요·완료 개수를 보여 주며, 전체 기록을 JSON으로 백업하고 복원할 수 있습니다.
- 입력 직후 창을 닫거나 새로고침해도 마지막 내용을 브라우저에 즉시 보존합니다.

## 실행

Windows에서는 `실행.bat`을 더블클릭합니다. Python이 없으면 Node.js로 자동 실행합니다.

직접 실행하려면 둘 중 하나를 사용합니다.

```bash
python server.py
node server.mjs
```

그다음 [http://localhost:8765](http://localhost:8765)를 엽니다.

API 키가 없어도 기본 기능은 모두 작동합니다. Claude 되묻기를 쓰려면 `.env.example`을 `.env`로 복사하고 `ANTHROPIC_API_KEY`를 넣습니다. 키는 서버에서만 읽으며 브라우저 코드와 저장 기록에는 넣지 않습니다.

## 파일 구조

```text
index.html   화면과 동작
server.py    Python 로컬 서버와 Claude 연결
server.mjs   Python이 없을 때 쓰는 Node.js 로컬 서버
실행.bat      Windows 자동 실행
PLAN.md      기능별 의도와 데이터 구조, 확인 항목
```

기존 `munje-balgulso-v1` 브라우저 기록은 새 필드에 기본값을 채워 그대로 엽니다. 민감한 개인정보, 비밀번호, 회사 내부정보는 기록하지 마세요.
